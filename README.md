# Data for: Early checks for planned datasets and data papers: Failure modes seen in abandoned dataset proposals

This repository holds the data supplement of the working paper "Early checks for planned datasets and data papers: Failure modes seen in abandoned dataset proposals" by Anna Lehtinen, deposited on Zenodo: https://doi.org/10.5281/zenodo.23144454 . Every file here is byte-identical to its copy in the Zenodo record; the SHA-256 of each file is listed in `MIRROR_MANIFEST.json`.

## About the paper

A planned dataset or data paper can lose its value before a line is written: a similar dataset is already public, the join between sources is empty, the license forbids release, or the base dataset is superseded. However, most such failures leave no record, so the next group meets them again at the same cost. In this study, we document every dataset idea that one data-paper project abandoned over six days: 20 records covering 19 ideas, each with its failure type, evidence and what would revive it. Our analysis reveals that, in these records, the most frequent failure was a close equivalent already published, followed by base datasets others had ingested, re-deposited or enlarged, and by joins that could not carry the intended information, such as a comparison column with one distinct value. Furthermore, in five cases some evidence that stopped the idea was already in files the project held, and two ideas were stopped only after a release was built. We provide the record table and low-cost checks for each failure type, such as searching files already held for competitors, counting distinct values per comparison column and reading provenance after a successful join. The frequencies are specific to one project, but in our judgement each check costs less than the failure it would have prevented, helping researchers and data stewards test a dataset idea before building it.
